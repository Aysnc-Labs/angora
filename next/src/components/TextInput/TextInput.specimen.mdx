<Specimen
  title="States"
  description="Error, success, and disabled are set via the state prop. Hover and focus come free from the native input — no state prop needed."

  <Stack>
    <TextInput label="Default" placeholder="Type something..." />
    <TextInput label="Error" state="error" hint="This field is required" value="Invalid input" />
    <TextInput label="Success" state="success" hint="Looks good!" value="Valid input" />
    <TextInput label="Disabled" state="disabled" value="Can't touch this" />
  </Stack>
</Specimen>

<Specimen
  title="With hints"
  description="Hint text explains format requirements or provides context. Always prefer hint text over placeholder — placeholders disappear as soon as the user types."
>
  <Stack>
    <TextInput label="Email" placeholder="you@example.com" hint="We'll never share your email." />
    <TextInput label="Password" placeholder="Enter password" hint="Must be at least 8 characters." />
  </Stack>
</Specimen>

- Always include a label. Placeholder text is not a substitute.
- Use hint text for format requirements or context. Use error hint for validation messages.
- `md` is the default size. Use `lg` for hero forms or landing pages. Use `sm` in dense UI.
