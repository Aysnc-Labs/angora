Inline status indicators and labels. Small, non-interactive.

  <Stack gap="sm">
    <Row>
      <span className="text-sm text-foreground">Production deploy</span>
      <Badge variant="success">Live</Badge>
    </Row>
    <Row>
      <span className="text-sm text-foreground">Staging deploy</span>
      <Badge variant="warning">Building</Badge>
    </Row>
    <Row>
      <span className="text-sm text-foreground">Preview deploy</span>
      <Badge variant="destructive">Failed</Badge>
    </Row>
  </Stack>
</Specimen>

- Badges communicate status, not actions. Never make a badge clickable.
- Use `default` for neutral labels, semantic variants for meaningful state.
- Prefer `sm` size inside dense UI like tables or lists.
